## 📖 О проекте

Репозиторий с интерактивными картами игровых миров. Сейчас здесь восемь игр — **Stellar Blade**, **Tainted Grail: The Fall of Avalon**, **Gothic 1 Remake**, **Dimraeth**, **Palworld**, **The Elder Scrolls IV: Oblivion Remastered** **The Elder Scrolls V: Skyrim** и **Ведьмак 3: Дикая Охота**. Каждая карта — это статическая страница без сборки: открыл, отметил найденное, закрыл. Прогресс сохраняется в браузере, а после входа через Google ещё и переезжает вместе с вами на другое устройство.

> - 🏷️ **Теги DLC** («Каменные сердца», «Кровь и вино») показываются в карточке метки; ссылки на другие метки в описаниях кликабельны.
> - ✅ **Прогресс** по каждой карте отдельно, экспорт и импорт в JSON, облачная синхронизация через Google — как на остальных картах; в общий прогресс не входят службы, задания, входы и указатели.
> - 🔄 **Пересборка данных:** `python3 build_data.py` в `witcher3-map/tools` (исходная выгрузка лежит в `tools/source/`).

## ✨ Возможности

### 🎮 Для игроков

> - ✅ **Отметки и фильтры.** Отмечайте найденное кнопкой в карточке метки или правой кнопкой мыши. Переключайте категории и следите за прогрессом по каждой из них.
> - ➕ **Свои метки.** Добавляйте собственные метки прямо на карту и ведите личный прогресс.
> - 💾 **Локальное сохранение.** Прогресс и пользовательские метки хранятся в браузере. Прогресс можно импортировать и экспортировать как JSON.
> - 🙈 **Скрыть отмеченные.** Одной кнопкой уберите с карты уже найденные метки — выбор запоминается.
> - 🏠 **Главная страница.** Библиотека игр с поиском, общим прогрессом по каждой игре и кнопкой «Продолжить» с последней открытой картой. Есть светлая и тёмная темы (по умолчанию — системная).
> - 🧩 **Единое меню на всех картах.** Кнопка «Главная», соцсети и блок входа одинаковы по размеру и положению в каждой игре (общая геометрия — `css/sidebar-common.css`), а цвета и стиль у каждой игры свои. Шапка меню подстраивается под узкие экраны и не налезает на кнопку «Главная».
> - 🖼️ **Адаптивные карточки игр.** Баннеры на главной сохраняют пропорции 16:9 и всегда видны целиком; колонки сами сворачиваются, когда карточке тесно.
> - 📺 **Статус стримера.** Кнопка Twitch показывает, когда канал в эфире, а YouTube — когда вышло новое видео.
> - ☁️ **Синхронизация между устройствами.** После входа через Google личные отметки и пользовательские метки синхронизируются через Cloud Firestore. Нет сети — данные остаются локально и отправятся, когда соединение вернётся.

## ⚙️ Как это работает

```text
  ┌──────────────┐     ┌──────────────────┐     ┌─────────────────────┐
  │  Карта и     │ ──▶ │  Ваш прогресс    │ ──▶ │  Браузер            │
  │  общая база  │     │  и свои метки    │     │  (localStorage)     │
  │  меток JSON  │     └──────────────────┘     └──────────┬──────────┘
  └──────────────┘                                         │ вход через Google
                                                           ▼
                                                ┌─────────────────────┐
                                                │  Cloud Firestore    │
                                                │  между устройствами │
                                                └─────────────────────┘
```

1. **Карта** — подложка из тайлов (в отдельных репозиториях `<игра>-assets` на GitHub Pages), поверх неё Leaflet рисует метки из JSON-базы. Одни карты используют систему координат `L.CRS.Simple`, другие — Web Mercator (EPSG:3857).
2. **Прогресс** сразу сохраняется в браузере — работает без аккаунта и без сети.
3. **Вход через Google** включает облако: отметки и свои метки появляются на всех ваших устройствах.

## 🚀 Запуск локально

Проект не требует сборки — это статические HTML-, CSS- и JavaScript-файлы. Запустите HTTP-сервер из корня репозитория:

```bash
python3 -m http.server 8000
```

Затем откройте **[http://localhost:8000](http://localhost:8000/)**.

> [!WARNING]
> **Не открывайте `index.html` двойным кликом.** Браузер блокирует `fetch` для файлов с адресом `file://` (политика CORS), поэтому JSON-базы меток не загрузятся и карта останется пустой. Всегда запускайте через HTTP-сервер, как показано выше.

> [!NOTE]
> Firebase и Leaflet подключаются с внешних CDN, поэтому нужен интернет. Для входа через Google домен сайта должен быть разрешён в настройках Firebase Authentication.

## ❓ FAQ

<details>
<summary><b>Нужен ли аккаунт, чтобы пользоваться картами?</b></summary>

Нет. Отметки и свои метки сохраняются в браузере. Аккаунт Google нужен только для синхронизации между устройствами.
</details>

<details>
<summary><b>Пропадёт ли прогресс, если пропадёт интернет?</b></summary>

Нет. Данные остаются на устройстве, а синхронизация повторится, когда соединение восстановится.
</details>

<details>
<summary><b>Как перенести прогресс без Google?</b></summary>

Экспортируйте прогресс как JSON и импортируйте его на другом устройстве.
</details>

<details>
<summary><b>Могу ли я изменить общую базу меток?</b></summary>

Общей базой управляет создатель карты. Вы можете добавлять собственные метки — они видны только вам.
</details>

<details>
<summary><b>Локально открывается пустая карта. Почему?</b></summary>

Скорее всего, страница открыта как файл. Запустите проект через HTTP-сервер — см. раздел «Запуск локально».
</details>
