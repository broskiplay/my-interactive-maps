# Аудит интерактивных карт — 20 ноября 2026

Проверены 12 доступных игр: Stellar Blade, Tainted Grail: The Fall of Avalon, Gothic 1 Remake, Dimraeth, Palworld, Oblivion Remastered, Skyrim, Ведьмак 3, Cyberpunk 2077, Hogwarts Legacy, Phantom Blade Zero и Red Dead Redemption 2. Silver Palace исключён по запросу владельца.

## Результат

Критических функциональных багов в доступных картах не найдено.

- Все 12 URL открываются, имеют карту и боковую панель.
- Проверены переключатели локаций/областей: элементы присутствуют, число вариантов соответствует конфигурации страницы.
- На картах с обычным MapLibre-потоком popup метки открывается, показывает категорию, заголовок, описание и действия «Важно», «Позже», «Заметка», «Отметить найденным», «Сообщить об ошибке» и «Неточное место?». Проверены все карты, кроме Dimraeth; на нём в нескольких тестовых координатах popup не появился.
- «Добавить свою метку» корректно переключается в режим «Кликните по карте… (отмена)».
- «О карте» раскрывает встроенное описание и список категорий; действия категории раскрывают дополнительные кнопки.
- На ширине 390 px у Stellar Blade, Gothic 1 Remake, Dimraeth и Cyberpunk 2077 горизонтального переполнения нет; меню и добавление своей метки доступны.

## Наблюдения, не подтверждённые как баги

1. В консоли повторяются предупреждения Canvas2D о `getImageData` без `willReadFrequently`. Это рекомендация производительности, не поломка. Исправление: при создании 2D-контекста canvas добавить `{ willReadFrequently: true }`, если этот canvas действительно часто читается через `getImageData`.
2. У Tainted Grail зафиксированы отменённые запросы к tile-файлам (`net::ERR_ABORTED`). При переходе и перерисовке карты такие отмены обычно означают замену устаревшего запроса, а не 404/500. Исправлять только после проверки Network на стабильной загрузке: проверить URL тайлов и не считать отменённый запрос ошибкой загрузчика.
3. Стандартная проверка сборки не выполнена: в рабочем окружении отсутствуют `node`/`npm`, а системный `python3` сломан отсутствующими Command Line Tools; локальный `.venv` содержит битую ссылку на Homebrew Python. Исправление окружения: установить Node.js/npm и Python, затем выполнить `npm run build --prefix web && npm run site --prefix web`, `python3 scripts/check_links.py _site` и `python3 scripts/spatial_lint.py`.

## Отдельно по Dimraeth

В ручном проходе карта, сайдбар и селекторы областей загрузились, но клики по пяти тестовым координатам canvas не открыли popup. Это единственный пункт, требующий дополнительной проверки на реальной точке метки. Если повторится, исправлять в игровом обработчике Dimraeth: проверить слой/обработчик click, преобразование координат и привязку данных маркеров к текущей области; не менять ID существующих меток.
