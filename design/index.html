Spatial UI

Один движок (css/spatial.css) для главной, служебных страниц и всех карт. Тема задаёт четыре цвета и свет/тень, всё остальное — слои глубины, тени, состояния — считается из них. Чем ближе слой к зрителю, тем он светлее.

Палитры

Одни и те же элементы в каждой теме — так проверяется единство. Новая палитра добавляется одной строкой в блок 1 движка; здесь она появится сама, если вписать её в список THEMES внизу страницы.

Слои глубины

Тема всей страницы — переключатель вверху. Нажатое и включённое возвращается на слой подложки и вдавливается.

Вдавленная плашка: поле, дорожка, тег
  1. 0Подложкафон страницы, боковая панель карты — --sp-base. Сюда же опускается нажатое (--sp-press).
  2. 1Карточки и блоки--sp-card + --sp-card-sh, при наведении --sp-card-sh-up.
  3. 2Кнопки, таблетки, чипы--sp-btn + --sp-btn-sh (контур, блик по верхней кромке, тень), при наведении --sp-btn-sh-up.
  4. 3Над картойте же кнопки + --sp-float: тёмное кольцо и тень, чтобы кромка читалась на любых тайлах.
  5. ∞Окнастекло --sp-glass с размытием и тенью парения --sp-overlay.

Токены

В правилах страниц — только они. Свои тени и смеси цветов ловит scripts/spatial_lint.py (запускается перед публикацией).

Примитивы

Классы для новой разметки. Специфичность нулевая (:where), поэтому любое правило страницы их уточняет.

Над картой: кнопки и стекло

Попап метки

Стекло с размытием, тонкий контур и блик, глубокая тень парения.

.sp-btn.sp-float — кнопка поверх тайлов · .sp-glass — окно над картой

Правила

  • Чем ближе — тем светлее. Подложка → карточка → кнопка; нажатое и включённое — цвета подложки и вдавлено.
  • Цвета игры — только в движке. Палитра карты: строка в блоке 1 css/spatial.css и <html data-game="…">. Стили страниц не задают свои фоны, тени и контуры.
  • Над картой — с кольцом. Неоморфный свет не работает поверх тайлов: кнопкам на карте --sp-float, окнам --sp-glass + --sp-overlay.
  • Свой акцент у элемента (карточка игры, соцсеть) — кольцо пишется в самом правиле: inset 0 0 0 1px color-mix(in srgb, var(--game-accent) 55%, transparent). Токены *-up берут акцент темы.
  • Осознанное исключение (объёмная иконка, свечение эфира) — /* sp-ok: причина */ в той же строке, иначе проверка остановит публикацию.
  • Панель карты — во всю высоту, у края экрана; плавающую панель с отступами пробовали и отказались.
